# Enable Folder Sharing

## UTM

1. Shut down the VM.
2. Open VM settings, select **Sharing**, choose **VirtFS**, and select a folder.
3. Start the VM and open `/home/beaver/Shared`.

## VirtualBox

1. Shut down the VM.
2. Open **Settings → Shared Folders**, add a folder, and enable **Auto-mount** and **Make Permanent**.
3. Start the VM and open the shared folder under `/media`.
